# rawsight
A raw packet dissector for x86-64 Linux. Captures and parses live network traffic at the binary level — no libpcap, no abstractions. Built to understand how protocol stacks actually work from the byte up.


## Architecture

rawsight uses a hybrid C/C++ design for the same reason 
network stacks themselves are layered:

**C (Capture Engine)** — raw socket management, epoll I/O loop, 
BPF filters, the pcap file reader and all protocol header parsing 
are written in pure C. Network programming at this level is a C 
domain — the structs map directly to wire formats and there are no 
abstractions between your code and the bytes.

**C++ (Analysis Layer)** — packet filtering and display are handled 
by a small C++ layer. Each dissected packet is converted into a 
`Packet` object, checked against the `Filter`, and printed by `Display`.

## Supported protocols

Currently the program recognizes and dissects:

- Link layer (2): Ethernet, ARP
- Network layer (3): IPv4 (later fragments are marked, not parsed), ICMP
- Transport layer (4): TCP, UDP
- Security: DTLS (detected by port 5684, not decrypted)
- Application layer (7): CoAP, including Uri-Path and Uri-Query

IPv6 and VLAN-tagged frames are skipped for now.

## Build

```
cmake -S . -B build
cmake --build build
```

Add `-DRAWSIGHT_SANITIZE=ON` to build with AddressSanitizer and UBSan.

## Usage

Live capture needs root (raw sockets):

```
sudo ./build/rawsight -i eth0 [-n <count>] [-p tcp|udp|icmp] [-f <ip>]
```

Or read a classic `.pcap` file (Ethernet link type, either byte order):

```
./build/rawsight -r mixed.pcap
```

| option | meaning |
|---|---|
| `-i` | live interface, e.g. `eth0` |
| `-r` | read from a pcap file instead of capturing |
| `-n` | stop after N packets |
| `-p` | protocol filter: `tcp`, `udp`, `icmp` (in-kernel BPF when capturing live) |
| `-f` | only show packets to/from this IP |

## Tests

```
ctest --test-dir build
```

Each test runs `rawsight -r` on a capture and compares the output with
`tests/expected/`. The edge-case captures in `tests/data/` are generated by
`tests/gen_pcaps.py`. After an intentional output change, refresh the
expected files with `RAWSIGHT_UPDATE_EXPECTED=1 ctest --test-dir build`.
